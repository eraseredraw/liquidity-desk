# БРИФ ДЛЯ МОДЕЛИ-ИСПОЛНИТЕЛЯ: Рефакторинг торговой системы

> Этот файл — контракт для LLM-модели, выполняющей рефакторинг. Модель читает его
> как системный промпт/первое сообщение. Результат работ возвращается основному
> агенту (opencode, deepseek-v4-flash) для верификации: ruff, pytest, ревью диффа.

---

## 1. КОНТЕКСТ ПРОЕКТА

Торговая система для фьючерсов E-mini S&P 500 (ES) и Nasdaq (NQ). Институциональная
ликвидно-ориентированная стратегия: уровни поддержки/сопротивления (H4/D1), зоны
ликвидности, POI, структура рынка. Сигналы генерируются от ключевых уровней с
подтверждением (фильтры: объем/свечи/тренд).

Стек: Python 3.13, pandas, requests. Без сторонних тяжёлых зависимостей.
OS: Windows. Кодировка файлов: UTF-8.

Способ запуска: batch-файлы `run_*.bat` в корне папки. Дашборд: `webui.py`
(localhost:8000, stdlib http.server + web/index.html).
